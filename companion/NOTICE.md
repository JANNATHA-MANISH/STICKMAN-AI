commercially, requires the author's permission.

No licence is granted by this directory either. Nothing here is legal advice —
if you plan to publish or deploy the prototype, ask the upstream author first.

The files in `companion/` (rig, layers, gestures, event adapter, UI, tests) were

upstream project is kept in every source header, and the original `index.html`
